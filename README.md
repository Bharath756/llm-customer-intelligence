# LLM-Powered Customer Intelligence & Decision Support System

## 1. Business Problem
Organizations collect large volumes of customer feedback and behavioral data,
but decision-makers struggle to convert this information into clear, explainable
insights. This project builds an LLM-powered system that retrieves relevant
customer evidence and generates grounded, actionable business insights.

## 2. Solution Overview
The system uses retrieval-augmented generation (RAG) to combine customer feedback,
behavioral signals, and large language models to produce evidence-backed summaries
and explanations that support customer and retention decisions.

## 3. System Architecture
- Data preparation and intelligent chunking
- Vector-based retrieval of relevant evidence
- Structured LLM prompting for insight generation
- Evaluation of groundedness and failure cases

## 4. Project Structure
- notebooks/ — Exploratory analysis and experiments
- src/ — Modular retrieval and LLM pipeline code
- data/ — Raw and processed datasets
- outputs/ — Generated insights and evaluations
